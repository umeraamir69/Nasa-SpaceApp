00 — WHAT CHANGED

The official statement, and what it confirms

Challenge: track and visualize surface change using NISAR (NASA-ISRO SAR) radar data, at any location worldwide. Fair game: wetland loss, wildfires, earthquakes, farming activity, glacier movement, and more — you choose which one(s).

Correction from earlier: the previous plan assumed Sentinel-1 as the default data source. NISAR is specified by name, so data access needs to be verified against NISAR's actual public availability — this is the first thing to check, this week, not at hour 2 of the hackathon.

02 — PICK YOUR CHANGE TYPE

Choose one, don't try to cover all

The challenge allows any surface-change type. Pick the one with the best combination of: clear visual signature in radar, well-documented real events, and achievable in your timeframe.

RECOMMENDED

Wildfire burn scars

Strong radar signature, many recent well-documented fires with exact dates, high real-world relevance (disaster response angle).

Best for: clear before/after story
STRONG ALTERNATIVE

Flooding

Very visible in SAR (water reflects radar differently than land), fast-onset events make dramatic before/after pairs.

Best for: disaster-response framing
HARDER

Glacier movement

Real and scientifically rich, but change is slower and less visually dramatic for a 3-minute demo.

Best for: teams with extra time to spare
HARDER

Farming activity / wetland loss

Interesting but the signal is subtler and harder to sell visually to non-expert judges in a short demo.

Best for: teams prioritizing novelty over demo drama

07 — QUICK START CODE

First technical step, right now

Get Earthdata access working and confirm you can pull real data before anything else:

pip install earthaccess rasterio numpy matplotlib

import earthaccess
earthaccess.login()  # uses your Earthdata credentials
results = earthaccess.search_data(
    short_name='NISAR_L1_...',  # confirm exact product name via Earthdata Search

If the NISAR product name/search returns nothing usable for your region yet, fall back to searching Sentinel-1 (short_name='SENTINEL-1') on the same portal as a placeholder while confirming NISAR's real coverage.

08 — TECH STACK, IN DETAIL

Languages, frameworks, and why

One language per layer, chosen for what SAR/geospatial work actually needs — Python has the strongest scientific/geospatial ecosystem, JavaScript owns the browser. Don't fight that split.

LayerLanguageLibraries / toolsWhy
Data accessPythonearthaccess, requestsOfficial NASA Earthdata client; handles auth + search + download in a few lines
SAR processingPythonrasterio, GDAL, numpy, scipyIndustry-standard geospatial raster I/O; numpy/scipy do the actual despeckle + change-detection math
Optional ML layerPythonscikit-learnOnly if classifying change types beyond simple thresholding — stretch goal, not MVP
Backend APIPythonFastAPI (or Flask)Fast to stand up, auto-generates docs, easy to serve GeoJSON endpoints
FrontendJavaScript / TypeScriptReact, Leaflet or Mapbox GL JSReact for UI state (before/after toggle, summary panel); Leaflet is free/open-source, Mapbox looks sharper if you want the polish
StylingCSSTailwind CSS (optional)Speeds up UI work under time pressure — skip if the team is faster hand-writing CSS
Data format (Python → JS)—GeoJSONNative to both rasterio’s ecosystem and every JS mapping library — no custom serialization needed
Version control—Git + GitHubRequired for submission anyway; set up the repo in Week 1, not event weekend
Hosting (for the demo)—Vercel/Netlify (frontend), Render/Railway (backend)Free tiers, deploy-on-push — judges can open a live link, no local setup needed

Setup once, in Week 1:

# Python side
python3 -m venv venv && source venv/bin/activate
pip install earthaccess rasterio numpy scipy fastapi uvicorn

# JS side
npx create-react-app echolens-frontend
cd echolens-frontend && npm install leaflet react-leaflet

If anyone on the team hasn’t used rasterio/GDAL before, budget real time in Week 2 to just learn reading/writing raster data — it has a learning curve that’s much better absorbed before the clock is running than during hour 8 of the hackathon.
